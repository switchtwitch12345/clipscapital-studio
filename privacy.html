Privacy Policy

Applies to: Clips Capital Studio, a self-hosted video clipping and uploading tool operated by an individual for their own YouTube channel.
Last updated: 26 November 2026

YouTube API Services
This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Who uses this app

This app has exactly one user: its operator. It is not offered to the public, there is no sign-up, and it runs only on the operator's own computer.

YouTube API Services: what data the app accesses

Clips Capital Studio uses YouTube API Services. When the operator connects their own YouTube channel with Google sign-in, the app requests two permissions:

  • youtube.upload: to upload short videos the operator has made to the operator's own channel.
  • youtube.readonly: to read the connected channel's name and ID, and the processing status and view count of videos the app uploaded.

The app does not access data about other YouTube users or viewers, and does not read comments, subscribers, messages or private analytics.

How the data is used

Channel name and ID are used to show which channel is connected. Upload status and view counts are shown to the operator so they can see whether a clip finished processing and how it is performing. The data is not used for advertising or any other purpose.

How the data is stored

OAuth tokens, the channel name and ID, and the IDs, statuses and view counts of uploaded videos are stored only on the operator's own computer, in the app's local data folder. Nothing is sent to any server other than Google's APIs.

Sharing

No data is sold, shared, or transferred to any third party. No advertising, analytics or tracking services are used.

Deleting your data and revoking access

  • Disconnecting the channel in the app deletes the stored tokens and channel details from the local data folder.
  • Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. Revoking stops all further access immediately.
  • To ask for any stored data to be deleted, email clipscapitall@gmail.com. It will be deleted within 7 days.
